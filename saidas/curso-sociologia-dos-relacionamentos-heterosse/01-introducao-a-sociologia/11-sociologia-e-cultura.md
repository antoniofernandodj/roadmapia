## Sociologia e Cultura

Imagine que você está em um restaurante no Brasil e pede um prato típico: feijoada. Enquanto isso, na França, alguém degusta um croissant, e no Japão, sushi. Essas escolhas alimentares não são aleatórias - são expressões de culturas distintas. A sociologia estuda justamente como a cultura molda e é moldada pela sociedade, criando padrões de comportamento que parecem naturais para quem vive dentro deles, mas que variam dramaticamente entre grupos humanos.

### O que é cultura na perspectiva sociológica?

Cultura não se limita a arte e literatura. É o conjunto complexo de:

1. **Símbolos**: Palavras, gestos, cores com significados específicos. O vermelho significa perigo no trânsito brasileiro, mas prosperidade na China.
2. **Valores**: Crenças sobre o que é desejável. No Brasil, a "cordialidade" é valorizada nas interações sociais.
3. **Normas**: Regras de comportamento. Chegar atrasado a uma festa é aceitável no Rio de Janeiro, mas rude em Tóquio.
4. **Tecnologia**: Desde o fogo até smartphones - ferramentas que modificam nossa relação com o mundo.

### Cultura material vs. não-material

- **Material**: Objetos físicos (celulares, roupas, prédios)
- **Não-material**: Ideias, crenças, valores (democracia, fé religiosa)

Exemplo prático: o casamento heterossexual brasileiro envolve:
- Cultura material: alianças, vestido branco, buffet
- Cultura não-material: monogamia, fidelidade, divisão de tarefas por gênero

### Etnocentrismo e relativismo cultural

Problema comum: julgar outras culturas pelos padrões da sua. Isso se chama **etnocentrismo**.

Exemplo real:
```python
# Código para calcular idade para casamento em diferentes culturas
idades_brasil = [18, 16]  # Homens, mulheres (com autorização)
idades_arabia = [18, 15]  # Idade mínima legal
idades_eua = [18, 18]     # Na maioria dos estados

def pode_casar(idade, cultura):
    if cultura == "Brasil":
        return idade >= (16 if genero == "F" else 18)
    elif cultura == "Arábia":
        return idade >= (15 if genero == "F" else 18)
    else:  # EUA
        return idade >= 18

# Testando
print(pode_casar(17, "Brasil"))  # True para mulheres
print(pode_casar(17, "EUA"))     # False para todos
```

Saída:
```
True
False
```

O erro seria presumir que "17 anos" tem o mesmo significado em todas as culturas. A sociologia propõe o **relativismo cultural** - entender cada prática dentro de seu contexto.

### Subculturas e contraculturas

Dentro de uma cultura dominante existem variações:

1. **Subculturas**: Grupos com características próprias que não desafiam a cultura principal (gaúchos no Brasil mantendo tradições regionais)
2. **Contraculturas**: Grupos que ativamente resistem à cultura dominante (movimento hippie nos anos 1960)

Exemplo brasileiro: o funk carioca começou como contracultura e hoje é parte da cultura mainstream.

### Cultura e mudança social

A cultura não é estática. Três mecanismos de mudança:

1. **Invenção**: Novos elementos (internet)
2. **Descoberta**: Compreensão de algo existente (teoria da evolução)
3. **Difusão**: Spread de traços culturais (sushi no Brasil)

Caso real: o divórcio no Brasil era proibido até 1977. A mudança legal refletiu e acelerou transformações culturais sobre família.

### Exercício prático

Analise este anúncio de casamento de 1950:

"José da Silva, honrado filho do coronel Silva, comunica seu casamento com D. Maria Pereira, digna filha do Dr. Pereira. Cerimônia na Matriz às 16h. Festa no Clube."

1. Quais elementos culturais estão presentes?
2. Como um anúncio similar seria hoje?
3. Que mudanças culturais isso revela?

**Solução comentada:**

1. Elementos de 1950:
   - Títulos honoríficos ("coronel", "D.")
   - Referência paterna (filho de...)
   - Local religioso (Matriz)
   - Espaço elitista (Clube)

2. Anúncio moderno poderia ser:
   "José e Maria celebram sua união. Cerimônia às 16h no Parque. Recepção no Espaço Verde."

3. Mudanças culturais:
   - Menos formalidade
   - Menos ênfase em hierarquias sociais
   - Locais menos tradicionais
   - Linguagem mais igualitária

Isso mostra como a cultura brasileira sobre casamento se transformou em 70 anos, refletindo mudanças em valores como igualdade e informalidade.
