## Casamento e Gênero no Brasil

Em uma pesquisa do IBGE em 2022, 72% das mulheres brasileiras casadas relataram ser as principais responsáveis pelas tarefas domésticas, mesmo quando trabalham fora em tempo integral. Esse dado revela como as expectativas de gênero moldam a experiência do casamento no Brasil, indo muito além da simples divisão de tarefas.

### A Construção dos Papéis de Gênero

O casamento brasileiro tradicional opera com um script de gênero bem definido. Vejamos como isso se manifesta na prática:

**Exemplo 1: Tomada de Decisão Familiar**
```python
# Pesquisa DataFolha (2021) - Quem decide principais compras da casa?
decisoes = {
    "Homem decide sozinho": 28,
    "Mulher decide sozinha": 15,
    "Decisão conjunta": 57
}
```

Saída real:
- Em 28% dos casais, apenas o homem decide compras importantes
- Em 15%, apenas a mulher decide
- 57% afirmam decidir conjuntamente

Apesar da aparente igualdade nos 57%, quando analisamos o tipo de decisão, encontramos um padrão:

```python
tipos_decisao = {
    "Finanças/Investimentos": 71% homem,
    "Educação dos filhos": 64% mulher,
    "Reformas na casa": 59% homem,
    "Alimentação": 82% mulher
}
```

Esse fenômeno é conhecido como "segregação horizontal de decisões" - diferentes áreas são "dominadas" por cada gênero, mantendo estereótipos mesmo em casais que se consideram igualitários.

### A Dupla Jornada Feminina

O problema central aparece quando analisamos a carga horária semanal:

```python
jornada_semanal = {
    "Trabalho remunerado": {"Homens": 44, "Mulheres": 39},
    "Trabalho doméstico": {"Homens": 10, "Mulheres": 22},
    "Cuidado com filhos": {"Homens": 7, "Mulheres": 14}
}
```

Total:
- Homens: 61 horas
- Mulheres: 75 horas

Esse desequilíbrio cria o que sociólogos chamam de "sobrecarga de gênero", onde mulheres acumulam funções profissionais e domésticas. A consequência? Um estudo da USP mostrou que mulheres em relações assimétricas têm 3x mais chances de desenvolver depressão.

### A Revolução Silenciosa

Nos últimos 20 anos, novos padrões emergiram:

1. **Casais com divisão igualitária** (15% em 2023 contra 3% em 2000)
2. **Mulheres principais provedoras** (22% dos lares)
3. **Homens donos de casa** (ainda apenas 2%)

Essas mudanças geram tensões. Um erro comum é assumir que jovens casais automaticamente terão relações igualitárias. Pesquisas mostram que:

```python
# % de casais que voltam a padrões tradicionais após 1º filho
recuo_tradicional = {
    "Antes do filho": 18% tradicional,
    "Após 1º filho": 63% tradicional
}
```

### Como Identificar Padrões de Gênero no Seu Relacionamento

Faça este exercício com seu parceiro(a):

1. Liste todas as tarefas domésticas regulares
2. Marque quem geralmente executa cada uma
3. Some o tempo gasto semanalmente por cada um
4. Compare com sua jornada de trabalho remunerado

**Solução esperada:**
Um casal com divisão equilibrada deveria ter uma proporção similar de horas totais de trabalho (remunerado + doméstico) para ambos. Se a diferença ultrapassar 15%, vale uma conversa sobre redistribuição.

### O Peso das Expectativas Sociais

O problema não é individual, mas estrutural. Quando mulheres deixam de trabalhar para cuidar da casa, são vistas como "dedicadas". Quando homens fazem o mesmo, frequentemente enfrentam comentários como "está desempregado?" ou "quem manda na casa é ela".

Essa assimetria se reflete até no vocabulário:
- "Pai babysitter" (quando cuida dos filhos)
- "Mãe trabalhadora" (como se fosse exceção)

A mudança começa pelo reconhecimento desses padrões e por pequenos ajustes diários na distribuição de tarefas e decisões.
