# C++ para Desenvolvimento de Jogos com Unreal Engine

Ao final do curso, o aluno será capaz de desenvolver jogos 2D de plataforma ou ação usando C++ nativo na Unreal Engine, compreendendo desde os fundamentos da linguagem até técnicas avançadas de programação de jogos.

**Para quem é:** Este material é para iniciantes em programação que desejam aprender C++ com foco em desenvolvimento de jogos. Não pressupõe conhecimento prévio de C++ ou de qualquer outra linguagem de programação.

> 160 de 160 trechos gerados.
