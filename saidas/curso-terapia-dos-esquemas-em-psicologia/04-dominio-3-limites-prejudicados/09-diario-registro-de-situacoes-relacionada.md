## Diário: Registro de Situações Relacionadas

Você está no metrô e alguém esbarra em você sem pedir desculpas. Imediatamente, pensa: "Que falta de educação! Essa pessoa deveria se envergonhar". Mais tarde, no trabalho, um colega pede para adiar uma tarefa combinada e você sente uma onda de irritação: "Ele sempre faz isso, ninguém respeita meus horários". Essas reações intensas a situações cotidianas podem ser sinais de esquemas do domínio Limites Prejudicados. Mas como identificá-los na prática?

O diário de situações é a ferramenta mais simples para capturar esses momentos. Não se trata de analisar (isso vem depois), mas de registrar com precisão os fatos, como uma câmera filmando a cena. Veja como funciona na prática:

**Exemplo completo de registro (Esquema de Direito/Grandiosidade):**
```
Data: 15/03/2023 - 14h30
Situação: Reunião de equipe onde meu projeto foi criticado
Fatos objetivos:
- João disse: "A parte técnica está boa, mas o cronograma é irreal"
- Maria acrescentou: "Concordo, precisamos rever os prazos"
Pensamentos automáticos:
-"Eles não reconhecem meu esforço"
-"Estão tentando me diminuir"
Emoções (0-100):
Raiva (80), Frustração (70)
Comportamento:
Respondi secamente: "Se soubessem fazer melhor, não estariam nesse cargo"
```

**Saída esperada:** Um registro como esse permite ver o padrão - a percepção de desrespeito às próprias capacidades leva a reações desproporcionais. O erro mais comum é registrar já interpretando ("Eles foram injustos comigo") em vez de descrever ("Dois colegas questionaram meu cronograma").

Compare com um registro mal feito:
```
Hoje foi injusto - atacaram meu trabalho sem motivo (já interpretando)
```

A versão correta separa claramente os fatos verificáveis das interpretações. Quando você relê depois, consegue identificar onde os esquemas distorceram a percepção.

**Outro exemplo (Autocontrole Insuficiente):**
```
Data: 16/03/2023 - 20h15
Situação: Decidir entre ir à academia ou ver série
Fatos:
- Plano inicial: treino das 20h
- Recebi notificação de novo episódio
Pensamentos:
-"Só hoje não faz diferença"
-"Amanhã compenso"
Emoções:
Alívio (90), Culpa (40)
Comportamento:
Assisti 3 episódios seguidos, dormi às 1h
```

**Exercício prático:**
Registre uma situação real dos últimos 3 dias onde:
1. Você exigiu algo de forma rígida (possível Direito)
OU
2. Adiou uma tarefa importante (possível Autocontrole)

Use o modelo:
```
Data/Hora: 
Situação: 
Fatos objetivos: 
Pensamentos: 
Emoções (intensidade 0-100): 
Comportamento: 
```

**Solução comentada para o exercício:**
```
Data/Hora: 17/03 - 09h00
Situação: Fila do banco
Fatos: 
- 5 pessoas na frente
- Atendente chamou quem chegou depois
Pensamentos: 
-"Isso é um absurdo, eu deveria ser atendido primeiro"
-"Eles não seguem regras básicas"
Emoções: 
Raiva (95), Impotência (60)
Comportamento: 
Bati na mesa, exigi falar com o gerente
```
Análise: O registro mostra claramente a sensação de merecimento privilegiado (Direito) pela reação desproporcional a uma espera normal. Note como os pensamentos refletem a expectativa de tratamento especial.
