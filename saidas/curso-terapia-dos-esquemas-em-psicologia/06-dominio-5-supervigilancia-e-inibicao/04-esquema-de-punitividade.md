## Esquema de Punitividade

Você já se flagrou pensando "eu mereço sofrer por isso" após cometer um erro? Ou sentiu que pessoas próximas deveriam ser castigadas rigidamente por falhas? Essas reações automáticas são marcas do **Esquema de Punitividade**, um padrão que distorce a avaliação de erros em três níveis:

1. **Autopunição** - "Não posso perdoar meus próprios equívocos"
2. **Punição alheia** - "Os outros devem pagar por seus atos"
3. **Rigidez moral** - "Deslizes são inaceitáveis em qualquer circunstância"

### O Código Penal Interno

Pacientes com esse esquema operam com um sistema de justiça particular. Veja como ele se manifesta na prática:

```python
# Exemplo de diálogo interno característico
def avaliar_erro(gravidade_erro):
    if gravidade_erro == 'leve':
        return "Fui negligente, mereço desconforto"
    elif gravidade_erro == 'moderado':
        return "Preciso sofrer para aprender"
    else:
        return "Nunca mais serei digno de felicidade"

print(avaliar_erro('leve'))  # Saída: "Fui negligente, mereço desconforto"
```

A mensagem de erro típica desse padrão surge quando a pessoa tenta adotar autocompaixão:

```

Sistema operacional requer punição como condição para continuidade.
```

### Raízes na História Pessoal

Esse esquema frequentemente vem de:

1. **Educação punitiva** - Pais que usavam castigos severos como principal método disciplinar
2. **Experiências de humilhação** - Ter sido exposto publicamente por falhas
3. **Modelos rígidos** - Cuidadores que não toleravam imperfeições

Um paciente relatou: "Aos 8 anos, quebrei sem querer um vaso da minha mãe. Ela me fez escrever 100 vezes 'eu sou desastrado e irresponsável'. Até hoje, quando erro no trabalho, repito mentalmente essa frase."

### Como Reconhecer a Distorção

O esquema se disfarça de "justiça", mas observe estas distorções cognitivas:

| Pensamento Automático | Distorção Correspondente |
|-----------------------|--------------------------|
| "Erros devem ser punidos severamente" | Pensamento dicotômico |
| "Se eu não me punir, serei uma pessoa pior" | Raciocínio emocional |
| "Todos notarão meu erro e me condenarão" | Leitura mental |

### Exercício de Identificação

Analise esta situação e identifique os elementos do esquema:

*Joana esqueceu o aniversário da amiga. Imediatamente pensou: "Sou uma péssima pessoa, não mereço ter amigos. Vou me afastar de todos como castigo."*

**Solução comentada:**
1. **Autopunição excessiva** - Classificar-se como "péssima pessoa" por um erro específico
2. **Generalização** - Estender o julgamento para todas as relações
3. **Solução punitiva** - Isolamento como forma de autocastigo
4. **Ausência de reparação** - Não considerar pedir desculpas ou compensar o esquecimento

O padrão saudável seria: "Foi um descuido, mas isso não define quem eu sou. Vou ligar para minha amiga, me desculpar e marcar um programa especial."

Este esquema mantém um ciclo vicioso onde o medo do erro paradoxalmente aumenta a probabilidade de novos equívocos, pela pressão excessiva que gera. A terapia trabalha para substituir esse padrão por um sistema de aprendizado adaptativo, onde erros são informações valiosas, não crimes a serem punidos.
