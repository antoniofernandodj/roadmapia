## Transtornos de Ansiedade

Um paciente chega ao consultório com queixa de "crises de ansiedade que parecem do nada". Ele descreve taquicardia, sudorese e pensamentos catastróficos como "vou morrer" ou "vou perder o controle" em situações cotidianas – pegar um elevador, falar em público, até esperar numa fila. Medicamentos ajudam nos sintomas físicos, mas não impedem que os episódios se repitam. O que a Terapia dos Esquemas oferece aqui é uma lente para entender o *porquê* dessas reações desproporcionais.

### O Mecanismo Ansioso nos Esquemas

A ansiedade patológica funciona como um alarme de incêndio defeituoso: dispara sem fogo real. Na Terapia dos Esquemas, esses falsos alarmes são frequentemente alimentados por esquemas do Domínio 5 (Supervigilância e Inibição) como:

- **Esquema de Negatividade/Pessimismo** ("Se eu não me preocupar, algo ruim vai acontecer")
- **Esquema de Vulnerabilidade** ("Estou sempre em perigo")
- **Esquema de Controle Excessivo** ("Preciso dominar tudo para não desmoronar")

Veja como isso se materializa na prática:

```javascript
// Exemplo de pensamento automático em ansiedade generalizada
function avaliarSituacao(situacao) {
  const esquemaAtivado = "Vulnerabilidade";
  
  if (esquemaAtivado) {
    return "Isso é perigoso! Vai dar errado!";
  } else {
    return "É apenas uma situação normal"; 
  }
}

console.log(avaliarSituacao("entrar em um elevador"));
// Saída real: "Isso é perigoso! Vai dar errado!"
```

O erro clássico aqui é tentar apenas racionalizar ("elevadores são seguros") sem trabalhar o esquema subjacente. O paciente intelectualmente sabe disso, mas o corpo continua reagindo como se estivesse em perigo real.

### Técnica de Intervenção: Diálogo com o Esquema

1. **Identificação**: Use o questionamento socrático para revelar o esquema:
   - "O que exatamente te assusta no elevador?"
   - "Como você se vê nessa situação?"
   - "Essa preocupação lembra algo da sua infância?"

2. **Externalização**: Nomeie o esquema como entidade separada:
   - "Parece que o 'Seu Alarmista' está tomando conta agora"

3. **Contra-argumentação**: Desenvolva um personagem alternativo:
   - "O que o 'Seu Realista' diria sobre essa situação?"

Exemplo de registro terapêutico:

| Situação            | Esquema Ativado      | Pensamento Automático       | Resposta Alternativa       |
|---------------------|----------------------|-----------------------------|----------------------------|
| Reunião de trabalho | Negatividade/Pessimismo | "Vão me achar incompetente" | "Tenho qualificações para estar aqui" |

### Erro Comum e Correção

**Erro**: Focar apenas nos sintomas atuais sem mapear os padrões de vida:
```markdown
Paciente: "Tenho medo de dirigir"
Terapeuta: "Vamos fazer exposição gradual"
// Resultado: a ansiedade migra para outro foco
```

**Correção**: Vincular à história de esquemas:
```markdown
Terapeuta: "Quando foi a primeira vez que sentiu esse descontrole? Algo parecido acontecia quando criança?"
// Revela padrão de pais superprotetores que reforçaram esquema de Vulnerabilidade
```

### Exercício Prático

**Caso**: Mulher de 32 anos com crises de pânico ao sair de casa. Histórico de pais extremamente controladores que a desencorajavam de explorar o mundo.

1. Qual esquema provavelmente está ativo?
2. Como você formularia o caso nos termos da Terapia dos Esquemas?
3. Que técnica específica usaria para trabalhar esse esquema?

**Solução Comentada**:

1. **Esquema de Vulnerabilidade** (Domínio 5) combinado com **Autonomia Prejudicada** (Domínio 2). O medo atual reflete a mensagem internalizada de que o mundo é perigoso e ela não tem recursos para lidar com isso.

2. **Formulação**:
   - Gatilho atual: sair de casa
   - Esquema: "Ficar sozinha é perigoso"
   - Origem: Pais superprotetores que a desencorajavam de ter experiências autônomas
   - Estilo de enfrentamento: Evitação (fuga de situações desencadeadoras)

3. **Técnica Indicada**: 
   - **Reencenação Imaginal**: Revisitar cenas da infância onde os pais a desencorajavam e reprocessá-las com um "adulto seguro" (técnica da cadeira vazia)
   - **Cartas aos Pais**: Escrever (sem enviar) como se sentiu em relação às restrições excessivas
   - **Experimentos Comportamentais**: Começar com saídas curtas acompanhada, depois sozinha, para construir autonomia real

Este caso mostra como a ansiedade não é o problema em si, mas o sintoma de esquemas mais profundos que, quando trabalhados, levam a mudanças duradouras.
