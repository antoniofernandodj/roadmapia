## Ferramentas para criação de wireframes

Ao planejar a estrutura e o fluxo de uma interface, escolher a ferramenta adequada para criar wireframes é fundamental para garantir agilidade, clareza e colaboração eficiente. Wireframes não demandam acabamento visual, mas precisam ser claros, organizados e fáceis de editar. A seguir, apresentamos duas ferramentas populares e acessíveis, que atendem a diferentes perfis de usuários e projetos: **Lunacy** e **Figma**. Ambas combinam simplicidade para wireframes de baixa e média fidelidade com recursos que permitem evoluir para protótipos mais robustos.

---

### Lunacy: ferramenta gratuita, leve e offline

Lunacy é uma aplicação para Windows, macOS e Linux que funciona offline, ideal para quem prefere ou precisa trabalhar sem conexão constante à internet. É gratuita e suporta arquivos no formato `.sketch`, comuns no design de interfaces, o que facilita a colaboração com designers que usam Sketch no macOS.

#### Recursos básicos para wireframes:

- **Ferramentas de desenho vetorial**: Retângulos, círculos, linhas e ícones prontos, que permitem montar rapidamente a estrutura do wireframe.
- **Componentes reutilizáveis**: Criar e salvar símbolos (botões, campos, menus) para reaproveitar em diferentes telas, mantendo consistência.
- **Textos simples e estilos**: Ajuste de fontes, tamanhos e alinhamentos para representar rótulos, títulos e descrições.
- **Exportação rápida**: Para PNG, SVG e PDF, facilitando compartilhamento e documentação.
- **Bibliotecas de ícones gratuitas**: Ícones básicos para navegação, ações e estados, que enriquecem o wireframe sem exigir desenho manual.

#### Exemplo prático em Lunacy

Imagine que você queira criar um wireframe simples para uma tela de login:

```plaintext
- Abra Lunacy.
- Use a ferramenta retângulo para criar a área do formulário.
- Insira dois campos de texto simulados com retângulos e coloque rótulos acima usando a ferramenta texto: "Usuário" e "Senha".
- Adicione um botão retangular com o texto "Entrar".
- Utilize um ícone de cadeado ao lado do campo senha para indicar segurança.
```

Esse processo simples cria um wireframe funcional, focado na estrutura e elementos essenciais, sem preocupação com cores ou estilos detalhados.

---

### Figma: ferramenta online, colaborativa e versátil

Figma é uma ferramenta baseada no navegador que permite criar wireframes, mockups e protótipos interativos. Sua versão gratuita é poderosa para projetos individuais e equipes pequenas. O diferencial do Figma está na colaboração em tempo real, ideal para equipes multidisciplinares que precisam revisar e iterar rapidamente.

#### Recursos básicos para wireframes:

- **Ferramentas vetoriais completas**: Retângulos, linhas, elipses, textos e formas personalizadas, com controle fácil e intuitivo.
- **Componentes e estilos compartilhados**: Crie símbolos como botões, campos e menus, que podem ser atualizados globalmente.
- **Bibliotecas públicas e templates**: Acesso a kits UI prontos, como Material Design e iOS, que aceleram a criação dos wireframes.
- **Protótipos simples**: Linkar quadros para simular navegação básica entre telas.
- **Comentários em contexto**: Equipes podem deixar feedback diretamente no arquivo.

#### Exemplo prático em Figma

Criando o mesmo wireframe de tela de login:

```plaintext
- Acesse https://figma.com e crie um novo arquivo.
- Com a ferramenta retângulo, desenhe a área do formulário.
- Insira caixas de texto para rótulos "Usuário" e "Senha" e retângulos para os campos.
- Crie um botão com um retângulo e texto "Entrar".
- Importe um ícone de cadeado da biblioteca de ícones integrada e posicione ao lado do campo senha.
- Use a ferramenta protótipo para conectar o botão a uma tela de sucesso fictícia, simulando a navegação.
```

Em poucos minutos, o wireframe está pronto para compartilhar com a equipe e receber feedback.

### Comparação prática: Lunacy x Figma

| Aspecto                 | Lunacy                          | Figma                             |
|------------------------|--------------------------------|----------------------------------|
| **Modo de uso**        | Aplicativo desktop offline      | Aplicação web online              |
| **Colaboração**        | Compartilhamento de arquivos    | Edição simultânea em tempo real   |
| **Recursos gratuitos** | Completo para wireframe básico  | Completo, com prototipagem simples|
| **Aprendizado**        | Interface similar ao Sketch     | Interface intuitiva e moderna     |
| **Templates e bibliotecas** | Disponível, mas menos integrada | Muitas bibliotecas e templates   |
| **Exportação**         | PNG, SVG, PDF                  | PNG, SVG, PDF, código CSS básico  |

### Erro comum ao escolher ferramenta

Um erro frequente é tentar partir direto para protótipos interativos complexos, ignorando a fase de wireframe simples e foco na estrutura. Ferramentas como Figma permitem essa transição, mas iniciar o wireframe já tentando usar todos os recursos visuais e prototipagem pode atrasar o projeto e confundir a equipe. Lunacy, por sua vez, é um ótimo começo para wireframes básicos, mas pode limitar a colaboração se a equipe não estiver centralizada.

---

### Exercício prático

**Objetivo:** Criar um wireframe simples para uma tela de cadastro de usuário, usando Figma ou Lunacy, incluindo:

- Campos para nome, e-mail e senha, com rótulos claros.
- Botão "Cadastrar".
- Indicação visual de erro (ex: retângulo vermelho) para o campo e-mail.
- Navegação simulada para uma tela de "Confirmação" ao clicar no botão.

---

### Solução comentada (exemplo em Figma)

1. Abra Figma e crie um novo arquivo.
2. Use retângulos para os campos e caixas de texto para rótulos: "Nome", "E-mail", "Senha".
3. Adicione um retângulo com texto "Cadastrar" para o botão.
4. Para indicar erro no e-mail, desenhe um retângulo vermelho contornando o campo e adicione um texto pequeno abaixo: "E-mail inválido".
5. Crie um novo quadro chamado "Confirmação" com uma mensagem simples.
6. No modo protótipo, conecte o botão "Cadastrar" à tela "Confirmação".
7. Teste a navegação clicando no botão.

Esse wireframe contém a estrutura clara, elementos essenciais, sinalização de erro e fluxo básico, cumprindo o papel do wireframe como esqueleto da interface.

---

Compreender as características e limitações de cada ferramenta ajuda a escolher a melhor para o seu contexto, facilitando a criação de wireframes que comuniquem com precisão a estrutura e o fluxo da interface, antes de avançar para o design visual e prototipagem.
