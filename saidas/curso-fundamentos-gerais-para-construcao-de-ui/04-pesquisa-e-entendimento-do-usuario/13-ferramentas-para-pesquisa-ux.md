## Ferramentas para pesquisa UX

Imagine que você realizou entrevistas, aplicou questionários e fez observações para entender seu usuário, mas agora tem um volume grande de dados para organizar, analisar e compartilhar com sua equipe. Como garantir que essas informações não se percam, fiquem acessíveis e possam ser interpretadas corretamente para orientar o design? A resposta está em utilizar ferramentas digitais básicas, acessíveis e eficazes para coleta, organização e análise dos dados de pesquisa em UX.

### Por que usar ferramentas digitais na pesquisa UX?

Mesmo em projetos simples, o volume de dados qualitativos e quantitativos pode ser grande e complexo. Anotações manuscritas, documentos isolados e planilhas desorganizadas dificultam a síntese e aumentam a chance de erros ou esquecimentos. Ferramentas digitais ajudam a:

- Centralizar dados em um único lugar.
- Facilitar a categorização e análise posterior.
- Compartilhar resultados com clareza e transparência.
- Automatizar tarefas repetitivas, liberando tempo para a interpretação.
- Garantir que a pesquisa seja auditável e replicável.

### Tipos de ferramentas essenciais para pesquisa UX

Embora existam softwares avançados pagos e específicos para UX, neste trecho focaremos em ferramentas digitais básicas, acessíveis a qualquer desenvolvedor que está começando a atuar com UX, sem necessidade de treinamento complexo.

#### 1. Ferramentas para coleta de dados

- **Google Forms** (ou Microsoft Forms): Permite criar questionários e surveys de forma rápida, com diversos tipos de perguntas (múltipla escolha, escala Likert, abertas).  
  - Exemplo: Você pode montar um formulário para medir a satisfação do usuário com um protótipo, coletando respostas quantitativas e qualitativas simultaneamente.  
  - Diferencial: Armazena automaticamente as respostas em uma planilha integrada, facilitando o acesso e análise posterior.

- **Gravadores de áudio e vídeo**: Para entrevistas e observações, usar o celular ou aplicativos como o **Voice Recorder** (Android/iOS) e gravação de tela são soluções simples para registrar as falas e ações dos usuários.  
  - Atenção: Sempre peça consentimento informado para gravações, respeitando a ética.

- **Blocos de notas digitais** (Google Docs, Microsoft Word, Notion): Para anotações durante entrevistas e observações, essas ferramentas facilitam o registro estruturado e colaborativo.  
  - Vantagem: Permite organização por tópicos, marcação de trechos importantes e compartilhamento em tempo real.

#### 2. Ferramentas para organização e análise de dados

- **Planilhas eletrônicas** (Google Sheets, Microsoft Excel): Indispensáveis para organizar dados quantitativos e também para organizar códigos e categorias de dados qualitativos.  
  - Exemplo prático: Imagine que você coletou respostas abertas em um survey. Você pode criar colunas para “Categoria da resposta”, “Sentimento expressado” e “Sugestão de melhoria”, preenchendo conforme analisa cada resposta.  
  - Recurso: Com filtros e tabelas dinâmicas, você pode agrupar e visualizar padrões rapidamente.

- **Ferramentas de mind mapping e organização visual** (Miro, MindMeister, Trello): Úteis para estruturar informações qualitativas, mapear stakeholders, criar personas e organizar insights.  
  - Exemplo: Após entrevistar usuários, você pode usar um quadro no Miro para agrupar dores e necessidades, criando clusters visuais que facilitam a síntese.

- **Softwares para análise qualitativa** (ATLAS.ti, NVivo) são poderosos, mas não essenciais para iniciantes. Para um primeiro contato, usar planilhas e notas já é suficiente.

#### 3. Ferramentas para apresentação e compartilhamento

- **Google Slides / PowerPoint**: Criar apresentações claras e com visual organizado para comunicar resultados da pesquisa pode ser feito com essas ferramentas, incorporando gráficos gerados em planilhas e imagens de protótipos.  
- **Documentos colaborativos** (Google Docs, Notion): Permitem que toda a equipe acompanhe os resultados da pesquisa em tempo real, comentem e sugiram melhorias.

### Exemplo prático: usando Google Forms e Google Sheets para pesquisa quantitativa e qualitativa

Suponha que você queira validar a usabilidade de um app com um questionário online.

1. Crie um formulário no Google Forms com perguntas como:
   - "Qual sua idade?" (múltipla escolha)
   - "Com que frequência você usa apps para finanças?" (escala de 1 a 5)
   - "Conte uma dificuldade que você enfrenta ao usar apps financeiros." (resposta aberta)

2. Compartilhe o link e colete respostas.

3. As respostas são automaticamente agrupadas em uma planilha do Google Sheets, onde você pode:

   - Filtrar e contar respostas numéricas para análises estatísticas simples.
   - Ler as respostas abertas e, numa coluna adjacente, classificar manualmente por temas (ex: “dificuldade com login”, “interface confusa”, “falta de ajuda”).

4. Com filtros e gráficos do Sheets, visualize a distribuição das respostas e identifique os principais pontos para melhoria.

### Erro comum: tentar analisar dados qualitativos sem organização

Um equívoco frequente é acumular textos longos de entrevistas e respostas abertas sem categorizá-los, o que torna a análise superficial ou impossível. A mensagem prática é: **não deixe dados qualitativos soltos, use ferramentas para organizar e codificar os conteúdos**.

Por exemplo, se você tentar ler uma planilha com 50 respostas abertas sem uma coluna para categorias, será difícil extrair padrões. O resultado? Insights confusos e decisões de design mal fundamentadas.

### Demonstração de organização simples em planilha

| Resposta Aberta                                      | Categoria           | Comentário                      |
|-----------------------------------------------------|---------------------|--------------------------------|
| "Tenho dificuldade para encontrar os relatórios."  | Navegação           | Problema na arquitetura da info |
| "Não entendo como adicionar uma nova conta."        | Usabilidade         | Falta de instrução clara        |
| "O app demora para carregar os dados."               | Performance         | Questão técnica relevante       |

Você pode filtrar e contar quantas respostas caem em cada categoria para priorizar melhorias.

### Exercício prático

Crie um questionário simples no Google Forms com ao menos 3 perguntas: duas quantitativas (ex: múltipla escolha, escala) e uma qualitativa (resposta aberta). Envie para pelo menos cinco pessoas, colete as respostas e:

1. Exporte os dados para o Google Sheets.
2. Organize as respostas abertas em categorias, criando uma coluna para isso.
3. Gere um gráfico simples mostrando a distribuição das respostas quantitativas.
4. Escreva um pequeno resumo (3 a 5 frases) destacando os principais insights da pesquisa.

---

**Solução comentada:**

- No Google Forms, use perguntas objetivas como "Com que frequência usa o app?" com escala 1 a 5, e uma pergunta aberta como "O que você mudaria na interface?".
- No Sheets, crie uma coluna ao lado das respostas abertas para "Categoria" e atribua temas como “usabilidade”, “design”, “conteúdo”.
- Use o recurso de gráfico de barras para a pergunta quantitativa.
- No resumo, destaque padrões claros, como “A maioria dos usuários usa o app diariamente, mas reclama da dificuldade em encontrar funções específicas”.

Esse exercício conecta prática e teoria, mostrando como ferramentas digitais básicas são aliadas indispensáveis para uma pesquisa UX eficaz, garantindo que os dados coletados sejam úteis e acionáveis.
